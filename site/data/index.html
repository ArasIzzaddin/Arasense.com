How to read these files. All projections share one method: models scored against the observed ERA5-Land climatology with the Aras Diagram (Izzaddin et al. 2024), trust-weighted, then projected for 2040–2059. Atlas files use a 5-model screening ensemble; the Bologna deep dive screens all 34 CMIP6 models. Screening-level outputs are for prioritization, not site engineering. If you use these files, cite the method paper and link back here.
